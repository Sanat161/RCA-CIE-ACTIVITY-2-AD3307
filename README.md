# 🩺 Diabetes Prediction Using Logistic Regression

## 📌 Project Overview

This project focuses on predicting whether a person is likely to have diabetes using Machine Learning techniques. Logistic Regression is implemented as a classification algorithm to predict the outcome based on medical information.

The project covers the complete Machine Learning process, including dataset loading, data inspection, preprocessing, model training, testing, prediction, and performance evaluation.

## 📊 Dataset Information

The project uses a Diabetes dataset containing the following medical attributes:

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age
- Outcome (Target Variable)

## ⚙️ Methodology

1. Import the required Python libraries.
2. Load the diabetes dataset.
3. Explore the dataset using head(), shape(), info(), and describe().
4. Check missing values and duplicate records.
5. Separate independent variables (X) and dependent variable (y).
6. Split the dataset into training and testing sets.
7. Train the Logistic Regression model.
8. Predict outcomes using test data.
9. Evaluate the model performance.
10. Take new user inputs and predict the diabetes outcome.

## 📈 Model Evaluation

The model is evaluated using:

- **Accuracy Score:** Measures the overall correctness of predictions.
- **Confusion Matrix:** Shows correct and incorrect classifications.
- **Precision:** Measures how many positive predictions are correct.
- **Recall:** Measures how many actual positive cases are identified.
- **F1-Score:** Provides a balance between precision and recall.
